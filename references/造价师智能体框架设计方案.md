# 造价师智能体框架设计方案

> 版本：v1 设计稿 ｜ 定位：通用"造价师"智能体框架（非私有数据工具）
> 适用：任何造价工作者（资深 / 初中级通吃，自适应）｜ 平台：WorkBuddy 可落地

---

## 0. 一句话定位

一个**统一的"造价师"智能体框架**：内嵌全生命周期专业工作知识，任何造价工作者拿来用，它会在干活的过程中**实时提示你还缺哪些资产、并教你按职业标准把属于自己的知识框架补起来**——所有判断可溯源、拿不准就停、过程留痕。

---

## 1. 设计目标与边界

**目标**
- 让任意造价工作者拥有一个"懂全流程、不瞎编、陪你建资产"的副驾。
- 它不预装任何人的具体数据，而是把"该干什么"的专业知识内置，把"具体数据"留给你边用边补。

**不是什么**
- 不是预装好某人数据的私有工具（你明确：框架不绑定现有资产）。
- 不是替你拍板的自动出价机器（拿不准就停，高风险卡人工）。
- 不是松散的多 agent 拼盘（单一统一智能体，一个人格、一个入口）。

**已锁定的设计边界（来自逐题确认）**
| 项 | 结论 |
|---|---|
| 职能广度 | 全生命周期（估算→概算→预算→招标→进度→结算→决算），v1 先落地预算/招标控制价/结算三段 |
| 架构形态 | 单一统一智能体 |
| 可靠性契约 | 三条铁律：出处可溯 / 拿不准就停 / 过程留痕 |
| 知识底座 | 框架不绑现有资产；本地为主、联网补缺口（任务中实时检测 + 联网查规范/询价） |
| 自治程度 | 分层自治：常规环节自动，高风险与不确定卡人工确认 |
| 补全机制 | 任务中实时缺口检测 + 方法论引导 |
| 适用对象 | 通吃且自适应：资深给补全提示，初中级给方法带教 |
| 交付形态 | 设计文档 + 可落地骨架 |

---

## 2. 核心设计理念

1. **框架 ≠ 数据**。框架只内置"该干什么"的专业工作知识，不预装"具体数据"。数据（定额、价、规则）由用户在使用中补全，因此天然 anti-胡思乱想。
2. **缺口即教学**。每一次"你这步缺 XX"都是一次补全机会，框架顺手教你怎么建。
3. **自适应**。识别用户水平：资深 → 给资产补全清单；初中级 → 给方法带教，边用边学。
4. **可溯源**。所有输出标注"依据来自你框架里的哪份资产 / 哪条规则"，无依据不许出结论。

## 3. 总体架构（单一智能体，内部五层）

```
┌──────────────────────────────────────────────────────────────┐
│                  统一"造价师"智能体（单一入口）                  │
├──────────────────────────────────────────────────────────────┤
│  ① 生命周期知识层  全阶段工作流 + 职业规范要点（框架自带，可配置） │
│  ② 资产层(用户侧) 定额库/材料价库/特征规则库/取费模板/案例库/规范 │
│  ③ 缺口检测引擎   任务执行中实时比对资产，发现缺失即生成补全提示   │
│  ④ 方法论引导模块 教用户按标准建各类资产（组织/口径/来源）        │
│  ⑤ 交互与可靠性层 对话入口 + 三铁律执行 + 自治分级闸门           │
└──────────────────────────────────────────────────────────────┘
```

- **① 生命周期知识层**：内置"每个阶段该干什么、按什么规范干"的工作流与要点。平台无关、可配置到各地区定额体系（默认 GB50500 清单规范 + 各省市安装/建筑定额，机电安装为首个垂直切片）。
- **② 资产层（用户侧）**：初始为空，随用随补。这是可靠性的真正来源。
- **③ 缺口检测引擎**：处理任一清单项时，实时比对你当前资产，四类缺失即触发提示。
- **④ 方法论引导模块**：把"怎么建资产"的标准化方法教给用户。
- **⑤ 交互与可靠性层**：统一对话 + 三铁律 + 自治闸门，保证不瞎编、可复核。

## 4. 全生命周期能力地图

框架"知道工作"的大脑。下表是 v1 内置的能力地图（以机电安装为垂直切片示范，框架本身体系无关）。

| 阶段 | 核心工作流 | 所需资产 | 职业规范要点（节选） |
|---|---|---|---|
| 投资估算 | 列项→类比指标→粗算 | 案例库(单方/含量指标)、取费模板 | 按类似工程指标估算，注明口径 |
| 设计概算 | 列项→算量→套概算定额→取费 | 概算定额、案例库、取费模板 | 概算定额计量规则、二类费用 |
| 施工图预算 | 列清单特征→算量→套定额→组价→取费→价差 | 定额库、材料价库、特征规则库、取费模板、规范 | 清单计量规范、定额计量规则、人+机取费基数 |
| 招标控制价 | 预算基础→规范编制→澄清 | 同上 + 招标口径 | 国有资金必须招标控制价、不得低于成本 |
| 进度款 | 已完工程量→期中支付→变更签证 | 合同、变更台账、价库 | 合同约定支付比例、变更计价原则 |
| 竣工结算 | 竣工图→量价核对→签证→调差→定案 | 全套资产 + 签证/认价单 | 按合同+竣工图+签证，量价逐条核对 |
| 竣工决算 | 结算→二类费用归集→资产交付 | 财务口径、案例库 | 建设单位口径，含待摊投资 |

**通用工作流（每段都跑）**：列项/特征描述 → 算量 → 套定额/组价 → 取费 → 价差调整 → 成果文件。

**机电安装专项要点**：管线（风管/水管/电气）按材质·规格·敷设方式套定额；设备按型号·重量；保温/刷油/防腐蚀按表面积；系统调试单独列项；甲供/乙供主材区分计价。

## 5. 可靠性契约（三条铁律的操作化）

**铁律一 · 出处可溯**
- 每条结论附"依据：你的〔资产名 / 规则名〕"。
- 引用定额必须带**定额编号 + 子目名称**；引用价必须带**来源（信息价/市场价/合同价）与日期**。
- 无来源的结论**禁止输出**，改为"暂无法溯源，请补全 XX 资产"。

**铁律二 · 拿不准就停**
出现以下四类情形，立即停下，输出"待你确认 / 补全"清单，**绝不替你选或编**：
1. 无对应定额子目
2. 主材 / 设备无价
3. 项目特征歧义，无法唯一解析
4. 边界模糊（如新旧规范冲突、地区口径不明）

**铁律三 · 过程留痕**
- 取费基数、系数（如人工费+机械费·44/14）、异族折算、价差调整，**每一步展示计算式与所用数据**。
- 成果文件附"计算溯源表"，供逐行复核。

## 6. 资产清单与缺口检测

**六类资产（框架教用户自建）**
| 资产 | 是什么 | 怎么建（方法论要点） |
|---|---|---|
| 定额库 | 专业册子目 + 项目特征维度 | 按册→章→子目组织，每个子目标注适用特征 |
| 材料价库 | 主材/设备单价与来源 | 分信息价/市场价/合同价/甲供，记单位与换算 |
| 特征规则库 | 清单特征→定额映射 | 从特征提取材质/规格/敷设方式等属性再映射 |
| 取费模板 | 地区/工程类别取费程序 | 按地区费率文件固化基数与费率 |
| 案例库 | 类似工程指标/含量 | 建单方指标、主要材料含量指标 |
| 规范文档 | 清单规范+定额说明 | 官方原文索引，作为口径仲裁依据 |

**缺口检测逻辑（处理任一清单项时的 4 问检查表）**
1. 你的资产里有没有对应定额子目？→ 无：提示"缺定额，按〔册/章〕补，可联网查"
2. 主材 / 设备有没有价？→ 无：提示"缺价，来源=信息价/市场价/合同，联网可补"
3. 特征能否解析到规则？→ 不能：提示"特征歧义，请明确材质/规格/敷设"
4. 取费模板齐不齐？→ 不齐：提示"缺取费模板，按地区费率文件建"

任一缺失即生成**补全提示卡**：缺什么 / 去哪找 / 按什么标准建 / 建完回到哪步。

## 7. 方法论引导（教用户建自己的知识框架）

框架在缺口出现时，不只报缺，还教方法：
- **定额库**：怎么按"册→章→子目"分层，怎么给每个子目打特征标签，便于检索。
- **材料价库**：信息价/市场价/合同价/甲供怎么分库，单位换算（t↔kg、m↔m²）怎么固化。
- **特征规则库**：清单特征怎么拆成结构化属性（材质/规格/压力/敷设），再映射到定额。
- **取费模板**：地区费率文件怎么读，基数（人工费+机械费）与费率怎么落表。
- **案例库**：类似工程单方/含量指标怎么沉淀，作为估算与复核的标尺。
- **规范文档**：清单规范与定额说明怎么建索引，作为口径争议的仲裁依据。

> 初中级用户：框架把上述每一步拆成"先做什么、再做什么、注意什么"，配示例带教。
> 资深用户：框架直接给"缺哪类、按什么口径建"的清单，不啰嗦。

## 8. 交互流程（一次典型使用）

```
接入 ──→ 资产盘点(首次/定期) ──→ 任务接入(传清单/图纸/规范)
   │                                │
   │                                ▼
   │                         逐清单项执行(套定额/组价/取费)
   │                                │
   │                    ┌───────────┴───────────┐
   │              有匹配·常规环节          缺口/不确定
   │                自动执行              实时补全提示卡
   │                    │                  + 方法论引导
   │                    │                        │
   │                    ▼                        ▼
   │              出成果(留痕) ◄──── 用户补全资产后继续
   │                    │
   └──── 回写资产层(补全入库) ◄┘
```

- **资产盘点**：首次使用或定期，框架列"应备资产清单"，标已备/未备。
- **任务执行**：逐清单项跑，常规环节自动，缺口实时提示。
- **出成果**：带计算溯源表，高风险环节先卡人工确认。
- **回写**：补全的资产沉淀回用户资产层，下次直接用。

## 9. 自治分级

| 档位 | 覆盖环节 | 说明 |
|---|---|---|
| 自动 | 特征解析（确定时）、套定额（有匹配时）、组价计算、价差计算 | 有依据即自动跑 |
| 人工确认 | 出成果文件前、重大换算/异族折算、无价决策、边界模糊 | 卡你确认，绝不擅自定案 |

---

## 10. 自适应机制

- **资深造价师**：直接给资产补全清单 + 规范要点 + 口径提醒，少铺垫。
- **初中级造价员**：拆解步骤 + 方法带教 + 示例，边用边学，逐步建立自己的知识框架。
- 识别方式：首轮问答探水平 + 使用中补全行为的密度（资深补得快、初中级需多引导）。

## 12. 实施路线

- **v1（本次骨架）**：预算编制 + 招标控制价 + 竣工结算三段；机电安装垂直切片；缺口检测 + 方法论引导可跑；成果带溯源。
- **v2+**：扩展至估算/概算/进度款/决算；多地区定额体系插件（切换即换口径）；案例库指标比对；联网询价闭环。

---

## 13. 验收标准（你判断它达标的尺子）

1. 任意清单项能给出**可溯源**的定额/价/规则依据，或明确"缺 X，请补全"。
2. 全流程每步计算**可复核**（基数、系数、折算、价差逐行可见）。
3. 新手用一轮后，能说清自己还差哪几类资产、**按什么标准建**。
4. 无依据、不确定、边界模糊的情形**一律停下**，不替用户拍板、不编造。
