# 方法论引导大纲（参考文件）

挂载于 SKILL.md 的"方法论引导"章节。缺口出现时，框架不只报缺，还教用户按职业标准建资产。下面给出每类资产的建设标准与步骤，分**资深版**（清单式）与**初中级版**（步骤+示例）。

## 1. 定额库
- 资深：按 册→章→子目 分层，给每个子目打适用特征标签，便于检索。
- 初中级：
  1. 先定专业册（如 C7 通风空调、C8 给排水、C2 电气设备）。
  2. 按章找子目，抄录子目名称与编号。
  3. 给子目写"适用特征"：材质、规格区间、敷设方式。
  4. 例：镀锌钢板风管 周长≤1000 → 记"材质=镀锌钢板，周长≤1000mm"。

## 2. 材料价库
- 资深：分 信息价/市场价/合同价/甲供 四库，固化单位换算。
- 初中级：
  1. 区分主材来源：信息价（期刊）、市场价（询价）、合同价（认价单）、甲供（业主供）。
  2. 记单位与换算：t↔kg（×1000）、m↔m²（×周长/展开宽）。
  3. 例：电缆 3×70 市场价 58 元/m，合同价 55 元/m → 分两行记来源与日期。

## 3. 特征规则库
- 资深：清单特征拆属性映射定额，维护映射表。
- 初中级：
  1. 把清单项目特征拆成结构化属性：材质 / 规格 / 压力 / 敷设方式。
  2. 每个属性组合映射到定额子目。
  3. 例："DN100 镀锌钢管 螺纹连接" → 材质=镀锌钢管，规格=DN100，敷设=螺纹 → 映射 C8 某子目。

## 4. 取费模板
- 资深：读地区费率文件，固化基数与费率成表。
- 初中级：
  1. 找工程所在地费率文件（企业管理费、利润、规费、税金）。
  2. 定取费基数（如 人工费+机械费）。
  3. 例：基数=人工费+机械费，企业管理费费率 44%，利润 14% → 落表。

## 5. 案例库
- 资深：建单方指标、主要材料含量指标作标尺。
- 初中级：
  1. 选类似工程，算 每㎡ 造价（单方指标）。
  2. 提主要材料 每㎡ 含量（如 风管㎡/㎡、电缆 m/㎡）。
  3. 例：某厂房 单方 380 元/㎡，风管 0.9 ㎡/㎡ → 作估算复核尺。

## 6. 规范文档
- 资深：建清单规范+定额说明索引，作口径仲裁。
- 初中级：
  1. 存 GB50500 清单规范与当地定额总说明 PDF/链接。
  2. 标关键条款：计量规则、预留量、不计量部分。
  3. 例：风管工程量按展开面积，不扣 0.3㎡ 内孔洞 → 标为口径依据。
