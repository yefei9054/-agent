# 造价师智能体框架 · 版本更新说明

## v1.2.0（2026-08-13）

本次为**理念与可用性**重大更新：把"智能体替你定做法"改为"智能体陪你长出来"。案例不再当标准答案，改用多层询问吃透你的能力与习惯，并新增面向普通用户的使用说明书与避坑指南。

### 新增（New）
- **`操作使用说明书.md`**（普通用户版）
  - 唤起/安装：WorkBuddy 与其他普通 agent（Claude/ChatGPT/通义/文心/Kimi 等）通用装法。
  - 首次使用：盘点资产、建立画像的完整话术。
  - 日常用法：一条清单从特征到组价的**完整可照抄对话流**。
  - 5 个高频调用示例（查缺补漏 / 拿不准停下 / 喂案例 / 换口径 / 改造成自己的）。
  - 配合自己资产用 + 改造成"你的" agent 的 4 步。
- **`常见问题与避坑指南.md`**
  - FAQ 11 条：能做什么 / 不能做什么 / 为何没有数据 / 怎么加资产 / 出错了怎么办 / 已知短板（算量、成果排版、出稿自检、联网询价、审计权限等如实列出）。
  - 避坑指南 8 条：别当黑盒、别让它猜、案例不照抄、资产靠自己、口径先定、无依据不用、涉密离线、变了要说。

### 变更（Changed）
- **`实战案例库与操作示例.md` 全面重构**
  - 案例**降级为"思路类别索引"**：每类只给"思考要点 + agent 该问你什么"，**不再预置任何具体映射/套定额规则**。
  - 新增**多层询问理解协议**：分 4 波递进提问（建画像 / 接任务 / 任务中 / 出成果前），先搞清你的专业、地区、口径、习惯再动手，绝不臆测。
  - 新增**agent 自我成长机制**：你的画像记 `user_profile`、你的做法记 `case_lib`、缺口记 `gap_log`；同类情形问得越少、越长越贴你。高风险项仍走三铁律，不替你拍板。
  - "蓝图口径速查"改为**示例模板**，必须用户确认后替换，框架不得硬编码。
- **`SKILL.md`（两个版本）**"实战案例库"章节改口为"仅作思路提示，不直接套用"，并补两份用户文档引用。
- **`造价师智能体框架设计方案.md`** 第 11 节文件清单更新，标注案例库新定位。

### 不变（Unchanged）
- 可靠性三铁律（出处可溯 / 拿不准就停 / 过程留痕）原样保留。
- 六类资产、记忆四层、数据库 schema、性格与行事准则、缺口 4 问、自治分级——结构不变。
- 单一统一智能体、全生命周期知识、自适应资深/初中级——定位不变。

### 升级方式
- **已装本地 skills 的用户**：用新 `落地骨架/` 覆盖 `~/.workbuddy/skills/造价师智能体框架/` 即可，无需重建资产库。
- **Skill Hub 用户**：重新安装 `cost-estimator-agent-framework.zip`（v1.2.0）。
- **其他 agent 用户**：把新 `SKILL.md` 重贴进系统提示，新两份文档作附件上传。
- 你的 `user_profile` / `case_lib` / `gap_log` 数据不受影响，跨版本保留。
