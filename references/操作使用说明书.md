# 造价师智能体 · 操作使用说明书（普通用户版）

这份说明书不假设你懂 AI、不假设你懂编程。你只要会"打字对话"，就能用起来。目标：让一个完全没接触过智能体的造价同行，照着下面的示例也能跑通。

---

## 〇、先搞清楚它能帮你什么

它是一个**造价师副驾**：你干活时它在旁边，帮你按职业规范做清单组价、发现你还缺哪些"家底"（定额/价/规则）、教你把属于自己的知识框架补起来。它**不预装任何人的数据**，所以第一次用一定是"它问你、你答"，问够了才顺手。

**它不替你**：拿不准就停、出成果前卡你确认、不瞎编。
**它帮你**：常规解析/套定额/组价自动跑、缺什么实时提示、按你的习惯越长越像你。

---

## 一、怎么把它"装"到手边

### 方式 A · WorkBuddy 用户（推荐）
1. 从 Skill Hub 搜 `cost-estimator-agent-framework` 安装；或把 `落地骨架/` 整个文件夹放进：
   - 用户级：`C:\Users\你的用户名\.workbuddy\skills\造价师智能体框架\`
   - 项目级：`你的工作区\.workbuddy\skills\造价师智能体框架\`
2. 重启/刷新 WorkBuddy，用触发词直接唤起：**"造价师智能体" / "造价副驾" / "资产补全"**。

### 方式 B · 其他普通 agent（Claude / ChatGPT / 通义 / 文心 / Kimi 等）
不需要装插件。把 `SKILL.md` 全文粘进"系统提示/自定义指令"，再把 `实战案例库与操作示例.md`、`操作使用说明书.md`、`常见问题与避坑指南.md`、`资产清单与缺口检测逻辑.md`、`方法论引导大纲.md`、`agent结构与记忆数据库设计规范.md` 作为附件上传给它即可。它就会按这套框架行事。

> 两种方式行为一致：都会先问你、再干活。

## 二、第一次用：先让它认识你（约 1 分钟）

直接发这段话（可照抄，括号里换成你的实际情况）：

> 我是做【机电安装】的造价，用【江苏 2014 安装定额 + GB50500 清单】，平时主要出【招标控制价和结算书】。我算【资深/初中级】，帮我建个画像，然后看看我缺哪些"家底"。

它会回你一份**资产盘点清单**（已备/未备），并问几个确认点。你照实答，它记进 `user_profile`，下次不重复问。

**示例回复（你看到的样子）：**
```
已记录你的画像：机电安装 / 江苏2014 / 招标控制价+结算。
资产盘点：
  ✅ 定额库：你本地有 15358 条（若你有的话）
  ⬜ 材料价库：未备 → 建议从信息价/合同价起步
  ⬜ 特征规则库：未备 → 边用边沉淀
  ⬜ 取费模板：未备 → 按江苏费率文件建
  ⬜ 案例库：空 → 把你做过的清单喂我
  ⬜ 规范文档：建议放 GB50500-2024 对照
先从哪类补？或先丢一条清单给我试？
```

## 三、日常用法：把一条清单交给它（完整对话流）

下面是一段**真实可抄**的对话。你照前两句发，后面的"它说"是它该有的反应范式。

**你：**
> 这条清单帮我组价：镀锌钢管 SC100 沿墙明敷，工程量 120m，阶段是预算。

**它（先跑缺口 4 问，缺什么问什么）：**
```
收到。我先跑缺口检查：
Q1 定额：SC100 镀锌钢管明敷 → 你库里有没有对应子目？（我初判应走"镀锌钢管敷设 公称直径100mm以内"，但需你确认编号）
Q2 主材价：SC100 镀锌钢管 当前价？来源是信息价/市场价/合同价？
Q3 特征：材质=镀锌钢管、规格=SC100、敷设=沿墙明敷，可解析 ✅
Q4 取费：你预算取费基数和费率按什么？（江苏一般 人工+机械，管理44/利润14，你确认下）
→ 还差【主材价】和【取费模板】两项，你给一下我就跑。
```

**你：**
> 主材价按本月信息价 58 元/m；取费按你说的江苏口径。

**它（补齐后组价，过程留痕）：**
```
补齐，开始组价（依据均溯源到你给的资产）：
定额 公称直径100mm以内：人工 X / 材料 Y / 机械 Z
主材 SC100 镀锌钢管 120m × 58元 = 6960 元（来源：本月信息价）
……取费：基数(人工+机械) × (管理44%+利润14%) = …
计算溯源表见下（略）。
⚠️ 出正式成果前确认：这个口径对吗？点"干"我出带溯源的清单。
```

**你：**
> 干。

**它：** 出正式成果（可要 Excel 表 / 带溯源清单 / 对话结论），并把这条"你的做法"建议沉淀进案例库。

## 四、几个高频调用示例（直接抄）

**示例 1 · 让它帮你查缺补漏**
> 帮我盘点我现在还缺哪些造价"家底"，按重要性排个序，告诉我每种去哪找、按什么标准建。

**示例 2 · 拿不准时让它停下别编**
> 这条清单特征写得很糊，你别猜，解析不了就停下来问我，给我选项。

**示例 3 · 教它长成你的样子**
> 这是我做对的一条：清单【……】正确套【定额编号 XXX】，思路是【……】。记进案例库，下次同类按我的来。

**示例 4 · 换项目/换口径先对齐**
> 下一个项目用【北京 2021 定额】，口径和上一个不一样，先按新地区重新建取费模板再干。

**示例 5 · 改造成你自己的 agent**
> 我只做【市政给排水】，把框架里的机电示例和口径都换成市政的，给我一份"我的专属配置清单"。

## 五、配合你自己的资产用（三句话记住）

1. **先盘点，再干活**——别一上来就扔清单，先让它认你、查你缺什么。
2. **缺口卡 = 你的待办**——它提示缺什么，你补什么；补完它自动接着跑。
3. **口径先定，别让它猜**——取费基数、费率、甲供乙供、借用原则，开工前跟它对齐一次，记进画像。

---

## 六、把它改造成"你的" agent（四步）

| 步 | 做什么 | 怎么告诉它 |
|---|---|---|
| 1 换专业 | 把示例从机电换成你的专业 | "我只做市政/土建，示例和口径全换" |
| 2 填口径 | 把示例费率换成你的地区文件 | "取费按【XX省XX版】文件，基数=…费率=…" |
| 3 接工具 | 接入你已有的定额库/价库 | "我的定额库在 path/xxx.db，读它别自己编" |
| 4 喂案例 | 把你的正确做法喂进案例库 | "这条清单+正确定额，记我自己的" |

改完你会发现：它问得越来越少，越来越贴你。这就是"自我成长"。

---

## 七、出错了 / 不放心怎么办

- 它说的依据你看不懂 → 直接问"这条依据来自你库里哪个资产？"它必须答得出（出处可溯）。
- 它开始编了 → 喊停，说"你没溯源就别输出"，它应改回"待补"。
- 结果明显不对 → 让它摊计算式（过程留痕），你逐行核。
- 想推倒重来 → "清空本次缺口轨迹/案例，重新按我的口径来"。

详见《常见问题与避坑指南》。
