# 资产清单与缺口检测逻辑（参考文件）

挂载于 SKILL.md 的"资产层 / 缺口检测"章节。框架不绑定任何人的现有数据，下列资产由用户在使用中补全。

## 一、六类资产定义与建设要点

| 资产 | 是什么 | 怎么建（要点） |
|---|---|---|
| 定额库 | 专业册子目 + 项目特征维度 | 按 册→章→子目 组织；每个子目标适用特征标签 |
| 材料价库 | 主材/设备单价与来源 | 分 信息价/市场价/合同价/甲供；记单位与换算(t↔kg、m↔m²) |
| 特征规则库 | 清单特征→定额映射 | 特征拆成 材质/规格/压力/敷设方式 等属性再映射 |
| 取费模板 | 地区/工程类别取费程序 | 按地区费率文件固化 基数与费率 |
| 案例库 | 类似工程指标/含量 | 建 单方指标、主要材料含量指标 |
| 规范文档 | 清单规范+定额说明 | 官方原文索引，作口径仲裁依据 |

## 二、缺口检测 4 问检查表（处理任一清单项时执行）

```
Q1 有对应定额子目？ ── 无 ──► 提示：缺定额，按〔册/章〕补；可联网查规范
Q2 主材/设备有价？  ── 无 ──► 提示：缺价，来源=信息价/市场价/合同价；联网可补
Q3 特征能解析到规则？─ 不能 ► 提示：特征歧义，请明确 材质/规格/敷设方式
Q4 取费模板齐？     ── 不齐 ► 提示：缺取费模板，按地区费率文件建
```

## 四、联网补缺口约定
- 本地资产无覆盖时（新材、无价、新规），联网查规范原文或询价，并把结果提示用户沉淀为资产。
- 联网所得必须标注来源与日期，记入材料价库/规范文档，供下次溯源。
